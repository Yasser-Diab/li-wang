## Notes

The page works as a static site with browser storage. When the Node server is running, memories and days are also saved into `data/app_data.json`.

Daily pranks live in `data/daily_joy_messages.json` and `data/daily_joy_messages_de.json`. Daily love notes live in `data/daily_love_messages.json` and `data/daily_love_messages_de.json`.
